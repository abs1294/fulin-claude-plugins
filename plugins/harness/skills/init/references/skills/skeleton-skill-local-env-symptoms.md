# 本機覆寫出問題時

**本 skill 不放內容，只指路**——每個檔該填什麼值、漏補的症狀，正本在 **`.claude/harness/local-overrides-guide.md`**；「哪些檔是覆寫」的正本是 {{覆寫清單位置}}。

## 照這個順序

1. Read `.claude/harness/local-overrides-guide.md`。
2. 先跑它第 1 節「最快的自檢」，把原始輸出貼出來。
3. 依症狀查它第 3 節的「漏補的症狀」欄，對到的那一列照「正確值」補；分不清是「環境變數切換」還是「手改常數」時看第 2 節——補法不同。
4. 開新工作樹或新分支的，照第 4 節帶齊。
5. 自檢全綠、症狀還在：照 03 的 A9 驗整條鏈路（埠號、跑的是哪一份程式、建置後有沒有重啟），還是不行就把它當程式的 bug 處理。

說明檔與實況對不上（值變了、症狀不一樣）時，改說明檔本身（黃區：改完當次講明改了什麼），不要在這裡或別處另外記一份。

變更紀錄見同目錄 `CHANGELOG.md`
