# 寓意科技報價單產生器（fable-quote）

## 這個 skill 做什麼

把一份開發案的內容，套進**寓意科技既有的報價單版式**，產出格式完全一致、可直接交客戶的正式報價單 `.docx`。

核心價值：**不要每次重畫 Word 格式**。手刻報價單版式（標題樣式、表格框線、底色、欄寬、字型）極易跑掉，且乙方資料與通用條款每次都要重打。本 skill 用一份**已脫敏的公司模板**（`assets/quote_template.docx`）＋一支產生腳本，你只需準備「這一案的內容」，其餘全部沿用。

## 何時用

- 使用者要對外報價：「做報價單」「幫客戶出報價」「這個開發案報價多少」
- 已有專案建議書 / 需求規劃，要轉成正式報價單
- 需要跟公司既有報價單格式一致（走報價程序、交客戶簽回）

## 產出流程

1. **蒐集這一案的內容**，整理成一份 JSON（schema 見下）。內容通常來自對話中的專案建議書、需求討論、或使用者口述。缺的欄位主動問使用者（尤其客戶統編、地址、聯絡人、報價日期、單價）。
2. **執行產生腳本**：
   ```bash
   python scripts/build_quote.py <你的 project.json> -o "fable報價單_<客戶>_<專案>.docx"
   ```
   腳本會套用 `assets/quote_template.docx`，動態展開明細列、自動算含稅金額與總計。
3. **轉 PDF 目視驗證**（強烈建議，確認無跑版）：用 Word 或 LibreOffice 轉 PDF，逐頁看金額、明細、專案定義是否正確。
4. **提醒使用者待填/待確認項**：客戶 Email、報價有效期、折扣等若未定，留白並提醒。

## JSON schema

只需填「這一案」的資料。範例見 `assets/example_project.json`（可直接複製修改）。

```jsonc
{
  "client_short": "汎銓",              // 用於輸出檔名
  "project_short": "ModernMES",        // 用於輸出檔名
  "quote_date": "2026/06/29",
  "valid_until": "2026/07/31",         // 報價有效期
  "unit_price": 10000,                 // 未稅單價（元/人天）
  "tax_rate": 0.05,                    // 稅率，通常 0.05
  "total_incl_tax": 267750,            // 選填：指定含稅總價；有給則校驗與明細加總是否一致

  "client": {                          // 甲方（查證公開登記資料，勿臆造統編/地址）
    "name": "汎銓科技股份有限公司",
    "contact": "趙芷暄", "phone": "03-666-3298",
    "tax_id": "27853425", "email": "tina_chao@msscorps.com",
    "address": "新竹市埔頂路27號1樓"
  },

  "project_name": "汎銓科技 – Modern MES V1.1 前端功能擴充開發案",

  "overview": {                        // 各欄位為字串陣列（多行）
    "manpower": ["1 位 PM：…", "2 位 前端工程師：…"],
    "tech": ["React.js …", "Tailwind CSS"],
    "notes": ["範疇限於…", "倘超出範圍另議…"],
    "deliverables": ["原始碼…", "測試報告…"],
    "browsers": "支援 Chrome、Edge、Safari、Firefox（建議最新版）。",  // 選填，有預設值
    "schedule": ["開發約 4 週…", "Phase 1 …：約 1 週"]
  },

  "phases": [                          // 服務明細，依階段分組；明細列數自動展開
    {
      "stage": "Phase 1　共用基礎與元件 階段",
      "items": [
        {"no": "#1-001", "name": "服務項目說明", "weeks": "約 1 週", "md": 2}
        // 金額自動 = round(md × 單價 × (1+稅率))；也可用 "amount": 21000 直接指定（含稅）
      ]
    }
  ],

  "project_definition": "本專案於…（一段完整專案定義，放進注意事項表首列）",

  "payment_schedule": [                // 選填；不給則沿用模板通用付款條款
    "請款分二期，各為總預算之 50%：",
    "第一期（前期款，50%）：…",
    "第二期（驗收尾款，50%）：…"
  ]
}
```

### 金額規則
- 每個項目給 `md`（人天），金額自動 = `round(md × unit_price × (1+tax_rate))`（**含稅**，與公司既有報價單一致）。
- 需要非人天比例的金額時，用 `"amount"` 直接指定（含稅整數）。
- 總價自動加總；若同時給 `total_incl_tax`，腳本會校驗兩者是否一致並在不符時警告。

## 用字與品質注意

這是**對外正式文件**，避免口語（例如「五五拆、一條龍、量大越划算、只負責本波、不知所措」等），改用書面商務語。若內容來自簡報/口述，務必先正式化再填入。客戶統編、地址等**須查證公開登記資料**，不可臆造。

## 更換模板

`assets/quote_template.docx` 是已脫敏的公司標準模板（保留版式與乙方資料）。若公司改版報價單格式，重新脫敏一份同名檔覆蓋即可，腳本邏輯不變（依賴表格結構：表1甲方、表2概覽+明細、表3注意事項、表4付款、表5簽回；明細以第 10 列為階段樣板、第 11 列為項目樣板）。
