# 上線前健檢：手動 TC 清單（tests/Project_Detail/SMOKE-manual.md）

> 只放自動套件（`tests/e2e/`）還沒涵蓋的案例。`smoke-run` 每輪會依等級篩出要跑的列、把「結果／嚴重程度／證據」清空，
> 另存成 `<report_dir>/manual-<本輪編號>.md`——**結果填在那份本輪副本裡，不要填在本檔**（本檔是清單正本，填了下一輪會被當成舊結果）。
> `smoke-report` 會拒絕產出報告，直到本輪副本每一列都填了「結果」與「證據」。

結果表（表頭至少要有 編號／功能／等級／結果／證據 五欄；嚴重程度、備註可選）：

- **等級**：寫 marker 名（P0／P1／P2），可寫多個（`P0、P1`）；空白＝每個等級都跑。篩選規則與 `SMOKE.json` 的 `levels` 相同。
- **結果**：PASS／FAIL／Partial／N.A.／Env Limit 擇一（不分大小寫）。Partial／N.A.／Env Limit 要在證據寫理由。
- **證據**：API 回應業務碼、DOM 讀回、資料讀回。CRUD 寫讀回結果（新增後清單看得到、編輯後值有變、刪除後消失），只看到成功提示不算。
- **嚴重程度**：FAIL 時填 Critical／Major／Minor；沒填會以「待判定」記進 issues。
