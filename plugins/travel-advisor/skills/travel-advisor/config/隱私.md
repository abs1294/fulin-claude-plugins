# 隱私：什麼不該寫進這個 skill

## 為什麼有這一條

```
skill 目錄是「設計上會被分享的單位」
  安裝在 user 層、所有專案都能用
  可能被 adopt 進 plugin monorepo
  monorepo 會 git push
                │
                ▼
        git 歷史不可逆
```

而狀態檔的規則是「每次更正當下寫回」—— 也就是這個 skill 被規則**強制持續累積**
個人資訊，卻（在 2026-11-01 之前）沒有任何一條規則說哪些不該寫。

---

## 三條規則

### 1. 醫療資訊用「風險標籤」，不寫診斷名

```
❌ <旅伴> 懷孕約 <N> 週；<年/月> 做過 <具體術名>（<原文病名>）
✅ 風險標籤：避免久站／避免生食／避免長距離步行／每 60 分鐘需坐著休息
```

**理由**：
- 規則真正需要的輸入是「要避免什麼」，不是「為什麼要避免」
- 診斷名對過濾候選沒有任何額外作用
- 這是**第三人的資料** —— 你可以同意分享自己的，不能代替別人同意

同理：長輩的慢性病寫成 `需定時服藥`＋`用藥禁用成分`，不寫病名。

### 2. 個資不落檔

```
❌ 使用者身份：<真名>
❌ 電話／email 寫在狀態檔
✅ 旅伴表只用 id 與稱呼（本人／太太／媽）
✅ 訂位個資：每次向使用者取，不落檔
```

### 3. 分享前必清

要把這個 skill 給別人、或 adopt 進 monorepo 之前：

```
1. 清空 state/ 底下所有行程檔（或只留範本）
2. 檢查 config/user-profile.md 的 A 段與 F 段
3. 跑一次掃描，判準如下（🔴 中英文都要，只掃中文會漏）

```
真名        中文姓名、羅馬拼音（LIN FU HSUAN 這種大寫雙詞）
email       [\w.+-]+@[\w-]+\.[a-z]{2,}        含第三者的，不只自己的
電話        \+?886\s?9\d{8} | 09\d{2}-?\d{3}-?\d{3}
密碼明文    密碼\s*[:：]?\s*[A-Za-z0-9]{4,20}
帳號        平台帳號／團隊名的【實際值】（Vercel、GitHub、訂房站）
            🔴 這一項我漏掃過兩次，兩次都是因為判準寫得太抽象。
               要抓的具體樣式：
                 whoami 回 `xxx`          ← 指令輸出裡的帳號值
                 <專案>-<團隊>.vercel.app ← URL 裡嵌的團隊名
                 帳號 xxx（團隊 yyy）      ← 狀態檔的紀錄欄位
               光搜「帳號」兩字會命中大量句子（「連上這個帳號的瀏覽器」），
               要搜【值】不是搜欄位名。
診斷名中文  環紮 子宮肌瘤 剖腹 …（具體術名一律換風險標籤）
診斷名英文  (?i)cerclage  post-cerclage  …  ← 中文清完這裡還會剩
本人孕週    (她|你們|太太|妻)\s*2[0-9]\s*週 | 2[0-9]\s*週\s*[0-9]\s*天
            ⚠️ 不要連航空公司的「30 週以下免適航申請」一起刪，
               那是規章門檻、不是她的週數
token       sk_ pk_ ghp_ gho_ 開頭、Bearer xxx
訂位編號    (訂位|預約|確認)(編號|番号|號碼)
卡號／護照  \b(?:\d{4}[- ]?){3}\d{4}\b、護照\s*[A-Z0-9]{7,9}
```

🔴 **替換不要用文字模式讀寫。** `read_text()` 會把 CRLF 正規化成 LF，
寫回時整檔換行就變了。用二進位讀寫：`read_bytes().decode('utf-8')`
→ 改 → `write_bytes(t.encode('utf-8'))`。
（我犯過：6 個檔的 CRLF 被壓成 LF，複驗才抓到。）
```

## 即時位置分享連結（2026-11-04 起）

連結長 `…!1s<Google 帳號 ID>!2s<token>!2e2`，本身就是讀取權限。處理原則：

| 可以 | 不可以 |
|---|---|
| 當下呼叫 `scripts/live-loc.py` 取座標 | 把連結、帳號 ID、token 寫進 state/、cache/、references/ |
| 回覆裡講「你在○○附近」 | 回覆裡印帳號 ID、姓名、頭像 URL（端點會回，腳本刻意不印） |
| 對話結束連結就丟 | 把座標寫進狀態檔當「上次位置」 |

掃描判準補兩條：`!1s\d{15,25}!2s`（分享連結）、`\d{21}`（Google 帳號 ID 常見長度）。
