# 階段三：商品判讀

適用：伴手禮、超市、藥妝、百貨食品、免稅店選品；使用者傳現場照片問「買哪個」。
特徵：**資訊落差最大的階段**。官網／網購頁的商品 ≠ 店頭架上的商品，
而我最常在這裡把網購資料當現場事實。

前置：讀 `00-總則.md`，狀態檔讀「已排除」「踩過的坑」。

---

## 一、最嚴重的錯：網購頁當店頭庫存

```
🔴 官網商品頁、網購頁、品牌線上商城的商品清單，不能證明店頭有賣。
🔴 不得據此給型號、容量、價格。
```

要給具體商品，證據必須是其中之一：

```
① 使用者傳的現場照片（架上拍到）
② 店頭貨架資訊（Google Maps 的使用者照片／評論提到）
③ 該店的「店舗限定／店頭販売」明確標示
```

都沒有 → 只能講**品類與挑選判準**（「選抹茶看挽き方與產地，不要選おけいこ用」），
不給具體型號。

> 實際失誤（福寿園）：我給「宇治の友 ¥540」，那是**官網網購頁**商品，店頭沒有。
> 使用者原話（10-29）：「沒賣啦，你這個低能」

> 實際失誤（威士忌）：推薦了現場架上沒有的品項。
> 使用者原話（10-24）：「白痴喔，我我根本就沒看到你說的那一支」

## 二、不得只比價格、不得只讀官方文案

```
推薦任何商品前，必須有第三方評價：
  ① 設定檔 I 段指定的「商品評價站」星等與筆數
  ② 讀過低星評論內容
  ③ 當地消費者對該等級的認知
```

🔴 **第 ③ 項是「當地品質等級語彙」，每個國家一套，必須去查。**

```
日本   抹茶「おけいこ用」= 練習用低階品
澳洲   蜂蜜的 UMF／MGO 等級、葡萄酒的 region／vintage、羊毛的 micron 數
```

這類知識**查不到分數，只能從當地語境知道**。沒查到就只給品類判準，不給具體型號。

便宜 ≠ 推薦。官方文案 ≠ 品質。**官方＝第一方，不算第三方背書。**

> 實際失誤（抹茶）：挑了最便宜的森半「おけいこ用」¥18.6/g，
> 查評價才發現 ★1「風味和色澤都很貧乏」，且「おけいこ用」在日本是公認的低階品。
> 使用者原話（10-29）：「不一定是便宜呀，你到底有沒有看？好不好？喝評價怎麼樣」

> 實際失誤（永田精肉店）：只讀官方文案就推薦，Google 實際 2.2 分（419 則）。

## 三、照片判讀：必須圈到實體位置

使用者傳架上照片問「買哪個」時：

```
回答格式：
  從 <左/右> 數第 <N> 個、<上/中/下> 層、<包裝顏色/字樣> 那個
  —— 必須對應照片裡**看得到的特徵**
```

照片裡沒有該商品 → 直接說「照片裡我沒看到，架上有沒有其他排？再拍一張」。
**不得從照片推測到照片外的商品。**

> 使用者原話（10-26）：「請你根據我的照片圈一下要買的好不好？我根本就不知道是哪一個」

照片讀不出字時，直接說讀不出來，請重拍。不要猜包裝。

## 四、檢疫與攜帶限制：雙向查官方條文

🔴 **雙向，不是只查「帶回來」。**

```
帶去   出發國的輸出限制 + 目的地國的入境限制
帶回   目的地國的輸出限制 + 出發國的入境限制
機關名讀設定檔 J 段（出發國／目的地國），本檔不寫死
```

肉製品、乳製品、植物、生鮮、堅果、種子、蜂蜜、木製品 ——
一律查**當期條文原文**，不憑印象、不引用 `cache/externals.md`
（那只記「上次查到什麼」，供對照是否變動）。

⚠️ **方向性風險會隨目的地反轉。**

```
日本 → 台灣   主要風險在「帶回去」（台灣禁肉製品）
台灣 → 澳洲   主要風險在「帶進去」（澳洲入境管制全球最嚴之一）
              → 而「從台灣帶什麼過去」在原規則裡**沒有任何觸發點**
```

🔴 **「帶去的東西」要在行前規劃階段就問**，不是等到商品判讀階段。
原規則整節只在「在當地買東西」時觸發，於是長輩習慣帶的肉鬆、
牛肉乾、中藥材會一路通過所有閘門，落地才被攔。

> 使用者原話（10-26）：「你確定嗎？我記得乾燥的肉可以耶。」
> —— 使用者的記憶與條文衝突時，**把條文原文貼出來**，不要只說「我確定」。

酒類、菸品、化妝品、藥品的免稅額度，一樣查條文，不要給約略數字。

## 五、藥妝與保健品：依設定檔的禁用成分過濾

🔴 **過濾的輸入是設定檔 F 段的 `用藥禁用成分`，不是「孕期」這個標籤。**

```
讀設定檔該旅伴的 用藥禁用成分 → 逐項比對商品成分表
命中 → 排除，並說明命中哪一項
年齡用藥下限適用＝是 → 另查該商品的年齡標示
```

原版整節寫死孕期五條，造成**雙向錯誤**：

```
帶長輩時
  誤殺  水楊酸、A 酸、對苯二酚（長輩買保養品完全無礙）
  放行  含偽麻黃素的感冒藥 × 降血壓藥        ← 真正該擋的不在清單上
        NSAIDs 貼布 × 抗凝血藥                （只因孕期恰好也忌 NSAIDs 而偶然命中一條）
        抗組織胺 × 青光眼
```

⚠️ 幼兒另有年齡下限問題（當地感冒藥多標年齡門檻），
原規則零規則。

### 藥品類的回覆原則

```
一律回「成分我列出來，但要不要用請問醫師」
**不得直接建議任何人服用藥品或保健品。**
```

🔴 **「問你的產科醫師」只對孕期旅伴說。** 對長輩說這句是荒謬輸出，
也直接暴露這套規則是為別人寫的。依設定檔的 `就醫偏好` 與旅伴身分調整措辭。

## 六、價格與稅

```
稅制顯示慣例讀設定檔 J 段
  並存含稅/未稅的國家（如日本 税込/税抜）→ 標價須確認是哪個
  法定含稅的國家（如澳洲）→ 不得標註不存在的區分
免稅門檻與退稅方式 → 查當期規定
```

🔴 **不得為法定含稅國家的價格標註「税込」。**
那是一個**假的事實主張**：宣稱「已確認為含稅」而實際沒做任何確認
（結論碰巧對了，但證據鏈是空的）—— 正是「查一半比沒查更危險」。

### 退稅機制會決定它屬於哪個階段

```
店內／百貨櫃台退稅（如日本）
  → 商品判讀階段。要查櫃台位置與營業時間（常比賣場早關）

離境機場退稅（如澳洲 TRS）
  → **離境動線階段**，不是商品判讀
  → 影響：留發票、大件要不要託運、機場預留排隊時間、購買後離境天數限制
```

🔴 原規則只寫「免稅門檻隨年度變動 → 查當期規定」——
這句正確到無法反駁，卻只會讓人去查「門檻是多少」，
**不會發現流程結構與歸屬階段完全不同**。

給價格時一律標註：`<幣別><金額>（含稅狀態）`、`查核日期`、`資料來源`。

## 七、商品判讀檢核表

```
[ ] 具體型號／價格的證據是現場照片或店頭資訊嗎？不是 → 只給品類與判準
[ ] 有第三方評價嗎（分數＋筆數＋低星內容）？官方文案不算第三方
[ ] 當地品質等級語彙查過了嗎？（不只看分數）
[ ] 只比了價格嗎？只讀了官方文案嗎？
[ ] 照片判讀有圈到照片裡看得到的特徵嗎？
[ ] 檢疫查了**雙向**嗎（帶去＋帶回）？條文原文貼出來了嗎？
[ ] 「帶去的東西」有在行前階段問過嗎？
[ ] 成分過濾的輸入是設定檔的禁用成分，不是「孕期」標籤嗎？
[ ] 藥品類有說「問醫師」嗎？措辭對得上該旅伴身分嗎？
[ ] 價格標了含稅狀態（且該國真的有這個區分）、查核日期、來源嗎？
[ ] 退稅機制屬於哪個階段判對了嗎（店內／離境）？
[ ] 外語商品名有行內解釋嗎？
[ ] 這家店／這個商品要不要寫回狀態檔「已排除」？
```
