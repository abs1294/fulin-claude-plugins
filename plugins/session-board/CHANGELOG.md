# Changelog

格式依 [Keep a Changelog](https://keepachangelog.com/zh-TW/1.1.0/)，最新在上。

## [0.1.0] - 2026-11-14

### Added

- 本機網頁：左邊 session 清單（依資料夾分組，圓點標示輪到你／執行中／沒事），右邊對話，下面輸入框。
- 看板裡的對話：直接在頁面上跟 Claude 對話，核准或拒絕它要做的動作，停止執行。重啟後接續原本的對話。
- 開新對話：Windows 資料夾選擇視窗、貼路徑、或點用過的資料夾。
- 終端機 session：唯讀顯示對話，把它的 Windows Terminal 視窗切到最前面。
- 終端機 session 搬到看板、看板裡的對話移到終端機。
- 檔案預覽：回覆裡提到且確實存在的檔案路徑可以點，在右側面板預覽圖片、PDF、文字與程式碼；Word／Excel／PowerPoint 由本機 Office 轉成 PDF 顯示。附「用預設程式開啟」「在檔案總管顯示」「複製路徑」。
- 戰情室：進行中的 session 正在做什麼與已跑多久、疑似卡住的標示、各 session 用量表、跨 session 最近做完的回合（點了打開對話並停在那一句）。
- 每個對話上方的數字列：花費、tokens、壓縮次數、目前 context、訊息數，以及子代理、skill、MCP、最近改過的檔案。
- 對話被壓縮的地方顯示為一條分隔線。
- 對話畫面：跳到自己上一次說話的位置、輸入 `/` 時列出符合的斜線指令、搬到看板時一併關閉原本的終端機視窗。
- 看板對話逐字顯示回覆；背景工作與子代理清單與「背景工作中」狀態；提問表單可直接作答（終端機 session 的提問顯示題目並導向終端機）；回覆裡的網址可點。
- context 佔比、5 小時與 7 天額度、看板對話的花費累計。
- 有對話在工作時，停止看板會被拒絕（`--force` 才強制）。
- 戰情室的每月用量：一個日曆月內所有 session 的 tokens 與 API 等值費用，含每日長條圖、各模型、各專案、花最多的 session，可翻看過去月份。
- 左側欄固定顯示帳號額度；開著的分頁在看板更新後自動重新載入並回到原位。
- 戰情室只留每月用量；各 session 一張表（本月費用、tokens、壓縮、context、訊息），還開著的有圓點、可點。
- 常駐：開著的終端機 session 預設常駐，關機或重開機後列在首頁可開回終端機（沿用原本的啟動參數）或搬進看板；自己關掉的不再常駐，列在「最近關掉的」。每個 session 可個別開關。設定頁可開「登入 Windows 時自動啟動看板」與「啟動時自動開回」。
- 看板開出來的終端機 session 現在看板看得到（開視窗時拿掉繼承來的 session 身分環境變數）。
- `/session-board` skill 與 `scripts/start.js`（啟動、查狀態、停止）。
- 設定與每月用量改存 SQLite 資料庫（`~/.claude/session-board/board.db`，Node 內建 `node:sqlite`）；舊的 `config.json`、`usage/*.json` 自動匯入。上個月的用量由看板自動算好存起來。
- 每月用量只讀新增的部分（掃描進度存資料庫）；本月數字 1 分鐘更新一次。
- 首頁「沒開著的對話」：最近 30 天的對話清單與搜尋，可開回終端機或搬進看板。
- 左側清單每個 session 多一行「你：…」（你最後說的話）。
- 隱藏 session；從看板結束終端機 session（按兩次）。
- SessionEnd hook：你自己結束的 session 立即不再常駐，看板沒在跑時也記得到。
- 收件：從 Gmail、Slack、Teams 抓訊息進資料庫並依路由分派到資料夾（移植自 customer-hub 的抓取、入庫與路由；不含擬回覆與寄出）。Gmail 以唯讀權限另外連接。
- 通知收進 plugin：session 做完或等你時跳 Windows 通知，點了切到那個 session（終端機視窗或看板頁面）；設定頁可關。
- 收件的 Teams 會自動認出哪個帳號是自己；Gmail 的 OAuth 用戶端可放在看板自己的資料夾；程式不再寫死任何個人路徑；非 Windows 啟動時直接說明。
- 收件判讀：每次抓取後自動判斷新進來的訊息是有效（要你做、等你回）還是無效（知會、雜訊），附一行要你做什麼；訊息頁預設只列有效的。
- 收件判讀改成「是不是你該處理的＋幾成把握」，有效的依把握高低排序，低於 70% 的以虛線框標示。
- 對話頁可以「載入更早的對話」（原本只顯示最近 120 則）。
- 左上固定入口「舊對話」：沒開著的對話清單與搜尋有自己的一頁；「Sessions」標題可點回首頁。
- 對話頁多一顆「↓ 我下一則」。
- 對話往上捲到接近已載入範圍的開頭，會自動往前載入；「↑ 我上一則」跳到底時也會自動載入更早的再繼續。
- 收件的聊天訊息（Teams、Slack）改成 Teams 式版面：對方在左附頭像、自己在右、同一人連續訊息合併顯示名稱與時間、跨日有日期分隔；勾選框貼在訊息旁，滑過才出現。
- 看板對話可以連續送訊息：Claude 執行中或等你回卡片時送的訊息會在看板排隊，輪到了一則一輪依序送出；排隊中的看得到、可以取消；按停止時沒送出的會放回輸入框。
- 看板對話的背景指令可以點開：右側面板顯示指令本身與輸出，執行中每 2 秒更新；做完的保留 10 分鐘可回頭看。
- 按「＋」開的新對話，沒說話就離開會自動關掉（有打字沒送出的會留著）。
- 舊對話依資料夾分組列出，按資料夾名稱展開。
- 常駐的勾選移到左側清單每個終端機 session 的右邊。
- 開回被關機或重開機打斷的 session 時，自動請它接著把做到一半的工作做完（設定可關）。
- 修正：看板剛重啟的頭幾秒，把開著的 session 誤列為「可還原」。首頁在窄視窗下不再撐出水平捲軸，清單長時可以捲動。
- 還原清單只有「還原」：終端機 session 一律開回終端機視窗（拿掉「搬進看板」的選項）。
- Gmail 改成抓所有收到的信（不再用標籤限制），而且是增量：只問上次之後的新信，只有出現新訊息的討論串才讀全文。判讀時新進來的訊息給全文，判讀過的只當上下文。
- 收件：抓取設定新增「你的信箱與名字」，判讀時告訴模型哪些話是你自己寫的（含別人來信裡引用的），不當成待辦。
- 修正：Gmail 信件標頭寫 big5、實際內容已是 UTF-8 時被解成亂碼（實測 41 封中 40 封）。
- 收件：「分派到資料夾」旁邊加上「選擇資料夾…」按鈕（訊息串上方與路由表單都有）。
- 收件：帶信開新對話或複製時，簽名檔會移除，附檔會下載到這台電腦並列出路徑。
- 收件：訊息串上方重排成「動作一列、屬性一列」；資料夾改成點一下就選、選了就分派，不再有輸入框加「分派」按鈕。
- 收件：信裡貼的圖片（內文顯示成「[影像]」）在帶入對話或複製時換成圖檔路徑，圖檔存到這台電腦。
- 還沒送出第一則訊息的對話不列在清單裡、不算進數量；離開時關掉（有打字沒送出的也一樣），沒有頁面開著它的在兩分鐘後自動移除。
- 收件帶進對話的內容改成「引用」：掛在輸入框上方，送出後收在你的訊息泡泡裡的卡片，和你自己寫的話分開。
- 輸入框上方的引用可以點開看全文，再點收合。
- 安全：預覽 Office 檔時關閉巨集；信件附檔加上網路來源標記；會執行東西的檔案類型不可一鍵開啟；不處理網路路徑；寄件者是不是你改成比對信箱本身。
