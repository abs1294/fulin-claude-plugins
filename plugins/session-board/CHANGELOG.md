## [0.14.0] - 2026-11-20
### Added
- 「檢查更新」按鈕：在螢幕右側，跟輸入框同一排（寬螢幕）。輸入框右邊放不下時，改放在右側跳轉鈕的上面；沒有輸入框的頁面放在右下角。按下去會先把 plugin 更新到最新；看板有新版時，看板自己重開成新版，網頁等它回來後自動重新整理，輸入框裡的字先存成草稿。有對話還在做事就不重開，並點名是哪幾個。這解決了「在看板裡的對話打 /session-board 永遠重啟不了」的問題：那個對話本身正在跑這個指令，會擋到自己。重開靠一個不屬於看板的小程式（`start.js --after <pid>`），等舊看板結束後再開新版。重開成新版這段已有單元測試，還沒用真的看板實際走過一次。
- 看板每天自己檢查一次更新（只讀，問 marketplace 最新版），「檢查更新」鈕只在有 plugin 落後、或裝好的看板比正在跑的新時才出現；滑過去會寫有哪些更新。
- 麥克風整理時，會帶上你說話時所在對話的標題、資料夾和最近 6 則內容，只用來把辨識聽錯的英文、指令、檔名、專案名改回來，不回答、不照做背景裡的內容。背景以一段 JSON 交給它，背景裡的文字假冒不了分段記號；換到別的對話說話時，改用新的整理程序，前一個對話的背景不會帶過去。實測：「session 波的的賴小秘書」→「session-board 的 LINE 小秘書」、「哈內斯的健檢 道克特 樸朗普特 奧迪特」→「harness 的健檢 /doctor prompt-audit」；沒有背景時改不回來，或只改對一半。
- 左欄上面那塊（戰情室到設定）可以拖曳下緣調整高度，放不下時那塊自己捲動；雙擊恢復自動高度。高度記在那個瀏覽器裡，手機上不出現拖曳線。

### Changed
- 收件：Gmail 還沒打開時，卡片上直接有「連接 Gmail」鈕，登入後會自動打開並開始抓，不必先去「抓取設定」。「你的信箱與名字」改成最下面的「你的其他信箱與名字（選填）」，因為登入的 Gmail 帳號已經自動算進去了。

### Fixed
- 終端機裡的 session 如果狀態記錄沒有狀態欄位（「狀態不明」，曾在 Mac 上看到），以前一律亮綠燈當成執行中；現在改看對話紀錄檔最後寫入的時間：90 秒內寫過算執行中，否則是閒置，超過 12 小時放進「放著沒動」。這樣就跟對話上方顯示的「閒置」一致了。

## [0.12.0] - 2026-11-20
### Added
- 語音輸入：送出鈕旁的麥克風，按一下開始講、再按一下結束。講的話預設由 Claude 整理（去贅字、補標點，不回答也不執行），整理時看板常駐一個 Claude，一句約 0.9～1.6 秒；設定裡可關，關掉就保留聽到的原文。整理失敗時也保留原文。手機要用麥克風，必須從 https 網址開：看板認得從 `tailscale serve` 進來的請求，會照「那台裝置」檢查，不當成這台電腦。
- LINE 小秘書（`/session-board:line`）：在 LINE 問看板現況，也能叫它送訊息、開新對話、停對話、回核可。line.json 填好才會啟動；它有自己的埠（127.0.0.1:4318），只回一個路徑，Tailscale Funnel 只轉到這裡，看板本身不上網際網路。簽章不對、不是你的 LINE 帳號的請求一律丟掉；會改東西的動作先把要做的事列給你看，你回「好」才做。附設定腳本 `scripts/line-setup.js`（status／edit／claim／funnel／webhook／start／off），機密不印出來。
- harness 待核建議多了「說明」鈕：Claude 用白話講清楚這條建議（改哪個檔、核可和駁回各會怎樣、建議怎麼選），只能讀檔、不能改。說明不存成對話，所以不會出現在你的 session 清單。再按一次會換一種講法（最多參考前 3 版）。建議內容由看板從專案自己的清單讀，不採用網頁送來的。

### Changed
- 收合的左欄只放「新對話」和要你處理的 session 頭像：在等你的是橘色，可能卡住的是紅色加「!」。滑鼠停在窄欄上，完整清單會浮出；移開、選了項目、或按 Esc 就收回。原本窄欄上那個看不出意思的數字已拿掉。
- 收件：搜尋會找全部分頁，結果依「有效／還沒判讀／無效／已完成」分組；判讀出的標題和摘要也比對得到（原本在「有效」頁搜寄件人名字，找不到被判成知會的那封）。列表上的判讀標籤移到第二行，標題可用整行；手機上來源（Gmail／Teams）改放到第三行的小字。
- 判讀：寄給你、還沒開的會議通知或邀請，歸成「要你做」，標題寫出席的日期時間；判讀時會告訴 Claude 現在時間（原本它自己猜日期，把明天的會判成已經過了）。
- 對話：你執行的 / 指令（包括按「下一步」按鈕送出的）會出現在對話裡，看板自己送的 /rename 不顯示。回答過的表單把你的選擇標在題目上（勾選、其他選項淡化），不再另起一塊。`檔名:行號` 會用程式碼開在那一行並標出來。指令清單在看板剛啟動時，會等使用次數算好再排（最多等 5 秒）。
- 看板在背景啟動的 Claude（btw、建議說明、核可判斷、收件判讀）不再載入你的設定、plugin 和專案的 hook。實測原本會註冊 30 個 hook，並真的執行 SessionStart hook；改成 `--setting-sources ''` 後是 0 個，`--resume`、讀檔照常可用。
- 設定裡「從其他裝置連線」關掉時，經 `tailscale serve` 進來的請求一律擋下，即使 serve 還開著也一樣（原本只靠位址檢查，自己的裝置仍進得來）。LINE 小秘書核准請求時，確認訊息顯示完整內容（原本截到 300 字）；裝成 plugin 時也找得到 goal2 的 LINE 設定。
- 介面（以 WCAG 量測）：暗色模式頭像的字、狀態標籤、收藏星號、檔案路徑小卡，對比都在 4.5 以上；桌機的點擊區至少 24px，觸控螢幕至少 44px（收件分頁圓點原本只有 8×8）。觸控時，收件 Gmail 卡片會跟著按鈕長高；手機上辦公室「沒開著的」那一列，按鈕改到名字下一行。

## [0.11.0] - 2026-11-19
### Changed
- 新對話打了字沒送出就離開：字留著（看板替你存草稿），對話不關、列在清單上叫「草稿：…」，回來時放回輸入框；送出或跑 ! 指令後清掉；收件匣帶進來的字沒動過照舊離開就關。送出的訊息在對話紀錄寫好之前一直留在畫面上（第一則可能比紀錄檔早 0.17 秒，之間重畫會把泡泡畫掉）。上傳檔案改成跟貼圖一樣：輸入框上方一張檔案小卡、文字裡標［檔N］，送出時在訊息最後附「［檔N］ 路徑」給 Claude 讀，你的泡泡裡顯示成可點開的檔案小卡；同一個檔（內容一樣）再傳沿用原本那份、同一則訊息裡只算一張。HTML 檔用看板當網頁伺服器預覽：同資料夾的圖片、樣式、程式一起載入，關在沙箱、不能連網、讀不到看板金鑰，以 . 開頭的檔與資料夾外的檔不給；手機上 HTML、PDF、Office 檔可在新分頁開。電腦版沒有按鈕單獨佔一行（選擇資料夾、顯示全部、重新查、看全部紀錄、開始合作、儲存資料夾、看各外掛的狀態、外觀四張卡一列）。只有一個額度時佔滿整列。收合左欄時底部那行不再擠成一字一行。選資料夾的視窗不再用透明的最上層視窗（疑似閃爍原因），改成畫面中央 1 像素的視窗，並一開就拿到鍵盤焦點
- 提示訊息改在畫面上方出現、點擊穿透（原本在下方擋住輸入框）。看板有新版時：看板對話輸入框裡的字先存成草稿再自動重新整理（有草稿後幾乎都被當成「還有沒存的東西」而不更新）；真的有沒回覆的卡片時，手機與收合左欄也看得到「看板有新版」（0.10.0 把手機底部那行藏了，開著的頁面一直停在舊版）。
- 模型與 effort 小視窗拿掉「套用／取消」：選好後點旁邊、按 Esc 或再按一次「模型」關掉就套用，沒改就什麼都不送；「換回 …」預先選好的也照樣套用。
- 舊對話：預設照舊列最近 30 天，辦公室每間與「沒開著」頁多「更早的 N 個 · 載入」，按了才讀更早的；搜尋一律不限時間（原本 30 天前的對話在看板上完全找不到）。
- 辦公室：沒被你拖曳排過、但裡面有開著對話的資料夾，排在「我的最愛」之後、你排過的其他資料夾之前（原本一律排在最後，連正在執行的也被擠到只剩舊對話的資料夾後面，看起來像沒顯示）。
- 審查修正：預覽網址只能在開它的那台裝置上用（頁面可把自己網址帶出去，沙箱擋不住）；預覽資料夾內不跟任何捷徑、不給資料檔（json/txt/md/csv/pdf）、擋 \\主機 路徑與 8.3 短檔名；同一份上傳超過 20 天再傳時在今天的資料夾加一個硬連結（仍只存一份，舊訊息路徑照樣能用）；草稿寫入全部排隊、送出最多等 3 秒；送不出去的字放回原對話（已切走就存成那個對話的草稿，框裡有字就接在後面）；同一句話連送兩次、長對話、剛跑過 ! 指令時，送出的泡泡不再消失或重複；HTML 預覽框載入修正。

## [0.9.0] - 2026-11-19
### Added
- 對話裡每個程式碼區塊右上角有複製按鈕：複製的是原本的文字（不含上色），按完變成打勾 1.5 秒。
- 寫到某個對話時，旁邊有「→ 看板接續」「終端機接續」（開著的是「→ 打開這個對話」）：認得的寫法照這台電腦 400 份對話紀錄統計——`claude --resume <編號>`（中間夾別的參數、`claude.exe`、`-r` 都算；在回覆的文字或程式碼、你打的話、工具的輸出裡都算），以及只寫編號的 `` `1a2b3c4d` ``、`` `1a2b3c4d-…` ``。資料夾不照回覆裡寫的（常是猜的），看板用編號找到那個對話的紀錄、照紀錄裡的資料夾開；查不到的編號、短編號對到不只一個對話、Windows 的 GUID、沒給編號的 `claude --resume`／`claude -c` 都不加按鈕。按鈕緊跟在那段指令後面；從手機開時只有「看板接續」（終端機會開在電腦的螢幕上）。
- 輸入框的「＋」多了「上傳檔案」：任何檔案（PDF、Word、Excel…）存到看板那台電腦的 `~/.claude/session-board/uploads/<日期>/`，路徑放進輸入框讓 Claude 讀；同名不覆蓋，上限 30 MB。從手機也能用。拖進來或貼上的非圖片檔也走這條路（原本會說「只能貼圖片」）。
- 左欄最下面那行多了「手機網址」：按一下複製手機要開的網址（Tailscale 位址）；Tailscale 沒開時直接帶你到設定。原本只在設定裡打開開關之後才看得到。
- 辦公室房間裡「測試有 N 項失敗」與「git 有檔沒 commit／沒 push」那一行多了「處理」：開一個新對話，第一句交代要做什麼（commit、push、改測試判準前都先問你）。
- `/session-board`（`start.js --refresh`）：先把這台電腦已裝的 fulin plugin 更新到最新，再重開看板（跑磁碟上現在的程式；看板上有對話在做事時不重開），最後回報 Tailscale 那邊有沒有又在聽。

### Changed
- harness 待核項目改成一鍵「核可」「駁回」：看板在那個專案的一個對話裡替你送出「核可 <編號>」，由 harness 原本的 hook 照常執行並記成你的決定（實測 2026-11-19：狀態 approved、紀錄 user-prompt）；同一個專案的核可都送進同一個對話，紅區的建議核可後 Claude 在那裡照建議改。
- 收件匣每一頁都是最新的在最上面（原本「有效」頁先按判讀的把握度排，11/10 的會排在 11/18 前面）。

### Fixed
- 看板的「plugin 自動更新」結果永遠顯示「都已是最新版」：plugin-manager 的 update-all.js 的 JSON 沒有 summary 欄位，改由它的 rows 組出「更新了哪些、從幾版到幾版、幾處」，仍落後與失敗照實列出，要重開 session 的地方也列出來。
- 看板每次啟動後約 3 秒會卡住 1.3 秒（ended 筆記一萬多份一次讀完），這時來的請求會等不到；改成背景分批讀，實測最慢一次回應 244 毫秒。`start.js` 等回應也從 1.5 秒放寬到 5 秒，不會再把剛啟動的看板誤當成沒在跑。

## [0.8.0] - 2026-11-19
### Added
- 四套外觀可以切換（設定 → 外觀）：A 清爽、B 溫暖柔和、C 深色控制台、D 原生大字。手機和電腦分開設定；沒選過的話手機（看瀏覽器的 user agent）用 D、電腦用 B。B、D 跟著系統的淺色／深色切換，C 一律深色；每套的文字對比度都在 4.5 以上。
- 上一頁：每一頁左上都有「←」（原本只在手機上有），回到你剛才那一頁；直接開進來的回清單。瀏覽器的上一頁／下一頁也在看板的頁面之間切換（原本會直接離開看板）。
