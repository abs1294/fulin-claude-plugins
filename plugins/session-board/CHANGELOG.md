## [0.25.0] - 2026-11-25
### Added
- 電腦負載示警：看板每 5 秒看一次整台電腦的記憶體和 CPU（每次不到千分之一秒），記憶體連續 1 分鐘、CPU 連續 2 分鐘超過門檻（預設都是 85%，在設定改，也能關掉），在鈴鐺和桌面通知，並寫出誰用最多（同一個對話連它開的程序算在一起）；降到門檻以下 5% 滿 1 分鐘自己收掉，半小時內不重複。
- 戰情室最上面顯示現在的記憶體和 CPU，「看誰用最多」列出前 8 名，是對話的可以點開。
### Fixed
- 設定頁跳到某一區時，標題被頂列蓋住。

## [0.22.1] - 2026-11-25
### Changed

## [0.22.0] - 2026-11-24
### Changed
- 合作成員改用看板給的固定代號（`S<流水號>-<短名>`，0.22.0 之前加入的沿用原本的名字）：跟著 session，不受標題、摘要、程序重開影響，加入別的合作也是同一個。看板對話每次啟動都帶 `--name`；看板開回終端機的也帶。
- 成員登記的名字變了，只在帳本註明，不再送訊息給其他成員（原本會叫醒對方，對方程序重開又改名，兩邊互相叫醒、花 token）。範本 `renamed.md` 拿掉。
- 合作進行中、24 小時內有成員動過時（`keepHours`），成員的程序不會因為閒置 15 分鐘被結束；看板重開後一分鐘內叫回來（不送訊息、不花 token）。
- 有代號的對話在看板改名只改看板上的標題，不送 `/rename`。
- 有代號的對話複製出來的，另給一個代號；看板開終端機時只帶這個 session 自己的代號，不會帶到別的 session 的。

- 設定「小模型判斷」寫清楚用在哪裡，並且收件判讀、推薦的外部 plugin 讀網址也照這個設定（原本固定 haiku）。
### Fixed

- 代號會被 Claude Code 記成標題：看板、舊對話清單、每月用量與通知都不把它當標題，用前一個標題。
- 成員從終端機移進看板（或移回去）之後，看板傳訊息改用它現在的位置。

### Changed
- 排程的「5 小時額度重置後」改成「額度重置後」：帳號沒有 5 小時額度時改等 7 天額度；7 天額度已經用完時也等它（5 小時重置了也跑不動）；選的時候會寫明等的是哪一個、幾點重置、還有多久；5 小時額度沒在計時就說不用等；沒有額度資料時說缺 cc-statusline。
- 每一頁的主要按鈕都在捲不走的標題列：「開始合作」「結束合作」（按兩次才結束）、「＋ 新增排程」與編輯排程的「取消／儲存」、收件抓取設定的「儲存設定」，原本在頁面最底下或會被捲走。
- 設定「一律不列出的資料夾」改成清單：一個資料夾一列，寫明收起幾個對話，可以一直加，加入與拿掉立刻生效。只寫資料夾的名字也可以（任何叫這個名字的資料夾，包括裡面的子資料夾），或寫完整路徑（家目錄可寫 `~`）。會收起超過兩成對話的，加入前先問。
- 所有要填資料夾的地方（開新對話、收件分派、分派規則、goal、排程）都可以只打名字：邊打邊列出用過的資料夾；名字只有一個就用它，有好幾個會列出來請你選。
- 額度改由 cc-statusline（1.9.0 以上）收集，看板只讀它的一個檔（`account-limits.json`）：不再自己問 Claude Code、不再記看板對話被告知的額度、不再讀各 session 的快照。數字超過 10 分鐘會寫是多久前的；沒裝或版本太舊，左下角會寫需要 cc-statusline。
- 「其他程式開的 session」的判斷拿掉兩條寫死的規則：claude-mem 的資料夾、2026-11-21 這個日期。現在只看 Claude Code 記的開法；某個資料夾要不要列，由設定「一律不列出的資料夾」決定（預設空白）。看板 0.4.0 之前自己開的舊對話因此也收進「其他程式開的」，改過名字的照常列出。
- 辦公室房間標題列的「＋」不再被切掉；手機上名稱自己一列，按鈕在第二列。
- 按鈕有底色：一般按鈕是淺藍底，駁回、刪除、丟掉、不要、拒絕這類是淺紅底，四種外觀的深淺色各配一組，不再跟背景同色。只有圖示的圓按鈕、分頁切換、對話右下角的跳轉按鈕維持原樣。

## [0.20.0] - 2026-11-23
### Added
- 每天上班統整：LINE 接通時，收件頁多一個開關。打開後每個工作日早上（預設週一到週五 09:30）用 LINE 告訴你今天要做什麼、還有什麼沒做、哪些對話在等你、今天有哪些排程。它是一筆排程，時間、星期在排程頁改，執行紀錄與錯過通知都跟其他排程一樣；收件頁也能「現在送一次」。
- 統整送出之前先核對你做了沒：向 Gmail 問每一串在對方最後一封之後你有沒有寄信、有沒有未寄的草稿，加上這段時間你寄出的信、所有專案的對話、你自己的 git commit，由 Claude（不給工具）判斷每件事做完、做到一半、沒做或說不準並寫出依據。收件裡沒標完成的事一件都不會省略，也不會自動替你標完成；查不到的部分（Gmail 讀不到、Claude 沒有判斷成功）會寫在訊息裡。
- 還沒開始的新對話只放了圖或檔（沒打字，或 Ctrl+S 暫存的只有附件）就切到別的對話，不再被自動關掉、附件跟著不見；左欄會列出來，寫有幾個附件還沒送出。
