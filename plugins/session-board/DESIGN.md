# 看板的設計規格

看板所有頁面共用這一份。四種外觀（A 清爽、B 溫暖柔和、C 深色控制台、D 原生大字）只換顏色，版面、字級、間距、元件全部照這份。

加新功能時只能用這裡列的數值和元件；要新增一種，先改這份文件，再寫程式。`tests/design.test.js` 會擋下規格以外的數值。

## 1. 數值

### 字級（6 種）

| 名稱 | 大小 | 用在哪裡 |
|---|---|---|
| `--fs-xs` | 12px | 標籤、時間、計數、說明小字 |
| `--fs-sm` | 13px | 次要文字：清單第二行、提示、表單說明 |
| `--fs-md` | 14px | 內文、按鈕、輸入框、清單主文字 |
| `--fs-lg` | 16px | 卡片標題、區塊標題 |
| `--fs-xl` | 20px | 次標題（設定頁的分區、對話框標題） |
| `--fs-2xl` | 28px | 頁標題（手機 24px） |

原本的 10、11 → 12；12.5、13.5 → 13；14.5、15 → 14；17、18 → 16；22、24 → 20；26、30 → 28。

### 間距（7 級）

`4 · 8 · 12 · 16 · 24 · 32 · 48`（px）。變數 `--sp-1` 到 `--sp-7`。

| 用途 | 值 |
|---|---|
| 頁面左右留白 | 電腦 32、手機 16（`--gut`） |
| 頁標題到內容 | 32 |
| 區塊與區塊之間 | 24 |
| 控制項（搜尋、篩選）到下方內容 | 16 |
| 卡片內邊距 | 20（手機 16） |
| 同一組元素之間（按鈕、標籤） | 8 |

### 圓角（3 種，加兩個形狀）

| 名稱 | 大小 | 用在哪裡 |
|---|---|---|
| `--r-s` | 6px | 標籤以外的小東西：程式碼、小縮圖 |
| `--r-m` | 10px | 按鈕、輸入框、選單、清單列 |
| `--r-l` | 16px | 卡片、對話框、面板 |
| 膠囊 | 999px | 標籤、篩選鈕 |
| 圓形 | 50% | 頭像、狀態圓點 |

### 陰影（3 種）

| 名稱 | 用在哪裡 |
|---|---|
| `--sh-card` | 卡片（貼在頁面上）、黏在頂端的列 |
| `--sh-pop` | 浮在上面的東西：下拉選單、對話框、側邊面板 |
| `--sh-ring` | 選中的外框（`0 0 0 2px` 主色） |

以下不算在這三種裡，可以照用：

- 指示線：目前所在項目旁的色條、底線（`inset`、`Npx 0 0`、`0 1px 0`）。
- 外框：`0 0 0 Npx` 的圈。
- 主要按鈕和用量數字卡的光暈（`var(--glow)`）。

## 2. 元件

| 元件 | 規格 |
|---|---|
| 頁面框架 | 左右 `--gut`；整頁最寬 1180，寬螢幕置中；表單類內容最寬 780，靠左 |
| 頁標題 | `--fs-2xl`、粗體；下方說明 `--fs-md` 灰字；左欄點得到的頁面不放「返回」，從清單點進去的頁面放「← 上一層名字」 |
| 卡片 | 白底、`--r-l`、`--sh-card`、內邊距 20；**卡片裡不能再放卡片**，卡片裡要分組用小標題或間距 |
| 按鈕 | 高 34（小 28）；四種：主要（主色底白字）、次要（淡主色底 `--btn`）、輕（淡灰底 `--fill`：返回、⋯、＋、關閉）、危險（淡紅底紅字）；**按鈕一定要有底色，不可跟背景同色**（左欄選單列、分頁、清單列不算按鈕）；同一列的按鈕同一個高度 |
| 標籤 | `--fs-xs`、行高 20、膠囊、左右 8；四種色調：成功綠、失敗紅、等待黃、中性灰 |
| 輸入框 | 高 40、`--r-m`、1px 邊框 |
| 清單列 | 一行高 40（兩行 56）；整列可點時不另放按鈕 |
| 區塊標題 | `--fs-sm`、粗體、灰字；上方 24、下方 8 |

## 3. 寫樣式的規則

1. 只用上面的變數，不直接寫數字（`0`、`1px` 邊框、`50%`、`999px` 除外）。
2. 「變成卡片」的樣式只能指定到某一個 class，不能用「某區塊裡的所有按鈕」這種寫法（`.loads button`）。2026-11-25 的卡中卡和白底按鈕就是這樣來的。
3. 新外觀不重寫舊規則；要改就改規格裡的變數。
4. 改完跑 `node --test tests/design.test.js`。
5. `--hover` 是透明的（四種外觀都是），不能拿來當按鈕或標籤的底色；要底色用 `--fill` 或 `--btn`。
6. 黏在頂端的東西都從 `--hbar`（頂列目前的高度）算起，不可蓋住頂列；寬高跟視窗比的要除以 `--zv`（字放大時才不會超出畫面）。
7. 間距還有舊值不在 7 級裡（2026-11-25 數過是 567 個）。測試只准這個數變少，改到哪裡順手換成規格值。
